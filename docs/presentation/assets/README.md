# Original pixel stickers

`sardines_pixel_stickers.png` is an original transparent four-quadrant sprite sheet, generated using the built-in
OpenAI imagegen tool on 30 Oct 2026. The deck uses the sardine on the cover and the heart at the close, with native
image crops. No Undertale sprites or characters are reused. The remaining stickers are available for later review.

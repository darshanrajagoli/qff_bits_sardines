# SwapPrint keynote demo

The story is in `narration.md`; `timeline.json` is the authoritative spoken/captioned script and edit plan.
The presentation matches the app: Carbon g100, a faint dot stage, thin grey notched frames, Departure Mono headings,
IBM Plex Mono text, violet #8a3ffc and detection magenta #ee5396. Maths retains Plex Sans glyphs where the Mono
font subset lacks Greek letters. It is an independent
student project, with no IBM logos or endorsement claim. Artwork is Hokusai's public-domain Great Wave (see
`data/artworks/SOURCES.md`). The backing pad is generated by `finish.py`; final narration is Rashida's original
recording. Microsoft edge-tts is available only for explicitly labelled timing references.

From the repository root, with the main app dependencies installed:

```powershell
# Recorder needs Playwright and its Chromium installation in the selected Python environment.
python video/record.py --url=http://localhost:8602

# Finishing environment: pip install -r video/requirements.txt; ffmpeg is on PATH.
video/.venv/Scripts/python.exe video/finish.py --no-tts --stills 6,25,49,59,65,84,96,125,150
# Final voiced export uses Rashida's real recording, not generated speech:
video/.venv/Scripts/python.exe video/ingest_narration.py video/out/Rashida_take1.m4a
video/.venv/Scripts/python.exe video/finish.py --human-manifest video/out/human/narration.json
video/.venv/Scripts/python.exe video/media.py
```

Before APP FINAL, a private banner preview can be rendered without changing published media or rebuilding the teaser:
`video/.venv/Scripts/python.exe video/media.py --hero-only --output .ai/hero_app_style.png`.
The light banner uses the same dot grid, notched frame and Departure/Plex Mono typography as the app.

Without `--url`, the recorder starts a headless app on port 8601 if needed. It generates deterministic facts with
the main repository Python environment, warms caches, then captures a clean 3840×2160 take. Each recording replaces
`video/out/raw`; preserve a wanted take before running it again. Failed actions abort the take. Rendering produces
1080p30 H.264/AAC, an SRT and a resolved timeline, with narration normalized to -16 LUFS. `--no-tts` gives captions
without synthesized speech; `--no-music` omits the original pad. `--reference-tts` explicitly creates a timing
reference and writes `reference_tts.mp4`. The final film requires Rashida's original audio and editorial approval.

The phone-recording instructions and frozen script are in `narration/`. The importer detects the four-second
section pauses, transcribes locally with faster-whisper CPU/int8, and aligns the expected script to real word
timestamps. Check `narration_review.json`, recognized text and cue timing before rendering. If pauses or retakes
make automatic splitting ambiguous, edit `detected_ranges.json` and pass `--ranges` to the importer; keep the
recording instead of asking for a new one. The first ASR run downloads an open tiny.en model into ignored `out/models/`.
Original audio stays local; the importer does not upload it to a transcription service.

Review the actual encoded output at the hook, diagram, verdict, first detected shot, heatmap, FRQI result, chart,
hardware beat and end card. Check synchronization as well as legibility. Compare displayed numbers against
`out/raw/facts.json`, the saved experiment CSVs, and `docs/QA.md`. F8 measures toy states on real hardware; app
Verify remains an analytical sampler. The full-image circuit is not a QPU result.

`out/` and `.venv/` are ignored. Commit source files and small README media, never renders or raw takes. Upload
the final MP4 privately to Drive or unlisted to YouTube and give Rashida its link.

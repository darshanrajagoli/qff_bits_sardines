# Production assets

- `DepartureMono-Regular.otf`: Departure Mono by Helena Zhang, SIL Open Font License 1.1; license included as `DepartureMono-OFL.txt`. Same font already credited by the app and presentation. Bundled here so the video does not depend on optional deck files.
- `live_app_qr.png`: project-generated QR for https://qffbitssardines-withoutthes.streamlit.app/ . Decoded from both source asset and actual rendered end frame with OpenCV. It contains only the public app URL.
- `sardine-pixel.svg`: original pixel mark drawn for team sardines. `brand_mark.py` places a small fading mark on the identity cards only. It is not an IBM logo or a game character.

Plex fonts come from the existing credited `swapprint/fonts/` bundle. No IBM logo or Undertale character/game asset is used.
